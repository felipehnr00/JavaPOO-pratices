# Exercícios de Programação Orientada a Objetos em Java

Este repositório contém exercícios desenvolvidos durante meus estudos de Programação Orientada a Objetos (POO) em Java.

## 📚 Conteúdos praticados

- Classes e objetos
- Construtores
- Encapsulamento
- Métodos com e sem retorno
- Lógica condicional (if/else)
- Manipulação de atributos

## 💻 Exercícios implementados

### 📦 Produto
Sistema simples de controle de estoque:
- Adição de produtos
- Remoção de produtos
- Cálculo do valor total em estoque

---

### 🏦 Conta Bancária
Simulação de operações bancárias:
- Depósito
- Saque com taxa fixa
- Consulta de saldo

---

### 🎓 Aluno
Sistema de avaliação de notas:
- Cálculo da nota final
- Verificação de aprovação
- Cálculo de pontos faltantes

## 🚀 Objetivo

Consolidar os fundamentos de Java e desenvolver lógica de programação com foco em orientação a objetos.

Este repositório faz parte do meu processo de aprendizado e será atualizado conforme avanço nos estudos.
